# Smart Cuff v3.1.232 (Default)

> **Withdrawn:** this installer unintentionally included ignored local
> diagnostic bundles. The release asset and tag were removed. Use
> [v3.1.233](https://github.com/mmjazini/smartcuff-releases/releases/tag/v3.1.233),
> which retains the heart logo and excludes all such runtime evidence.

- Restores the previous transparent Smart Cuff heart logo in the GUI,
  taskbar, installer, Windows uninstall entry, Start Menu, and desktop
  shortcut.
- Removes the superseded product-photo source so future builds retain the
  operator-selected heart artwork.

Firmware remains `rev27v-followup-223`; no control behavior changed.

## Windows SmartScreen / Unknown publisher

This official installer is currently unsigned. If Windows shows **Windows
protected your PC**, download only from this repository, verify the file is
`SmartCuff_Setup.exe`, select **More info**, then select **Run anyway**.
