# Smart Cuff v3.2.37 (Valinor)

## Windows SmartScreen

This installer is currently unsigned, so Windows may display **Windows
protected your PC** and show **Unknown publisher**.

Only for the official installer downloaded from this GitHub release:

1. Select **More info**.
2. Verify the file name is `SmartCuff_Setup.exe`.
3. Select **Run anyway**.

Do not continue if the file came from another source or has a different name.
The SHA-256 checksum is attached to this release for independent verification.

## Changes

- After all interactive first-time setup checks succeed, Smart Cuff now opens
  automatically.
- Automatic updates retain one controlled relaunch and do not open a duplicate
  GUI process.
- The installer includes the Valinor GUI, help/manual files, validated released
  calibration profiles, and firmware `v3.2.27` (`rev27v-gauge-27`).
- Firmware and control behavior are unchanged in this release.
