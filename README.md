# Smart Cuff operator downloads

This repository distributes reviewed compiled Windows applications and their
SHA-256 checksums. Default and Valinor have separate automatic update feeds.
The application verifies release URLs, byte counts and checksums before updating.

The installers preserve recorded data and device calibration. NI-DAQmx is an
optional separate installation from NI. On unsigned first installations, use
Windows **More info > Run anyway** after checking the downloaded installer.

Engineering source, research downloads and source-bearing historical bundles
are restricted to authorized maintainers. Older public copies cannot be recalled.
Compiled distribution reduces readable source disclosure; it does not guarantee
protection against reverse engineering or copying.
